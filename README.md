# SOSEMANUK — repo khung cho nhóm

**Đây là skeleton không có code.** Tất cả các file `.py` đã được tạo ở đúng vị trí nhưng đều có kích thước **0 byte**. Chưa có thuật toán chạy được và chưa có test nào có nội dung.

- `docs/conventions.md`: quy ước word, IV, FSM, checkpoint.
- `docs/module_contracts.md`: chữ ký và trách nhiệm module.
- `docs/team_plan.md`: đề xuất chia nhóm.
- `docs/test_plan.md`: gate nghiệm thu.
- `tests/vectors/`: dữ liệu oracle (đây là dữ liệu test, không phải code).
- `src/sosemanuk/`: các module trống để cả nhóm tự lập trình.
- `tests/`: các module test trống để mỗi thành viên viết.

Có thể nhập repo vào VS Code. Khi viết xong `run_tests.py` hoặc test files, chạy theo kế hoạch trong `docs/test_plan.md`.
